# API 概览

Askademic 后端提供 REST API，路径前缀 /api/v1，数据格式 JSON；问答类接口以 SSE 流式返回。

## 接口分组

- 认证与租户：登录、注册、邀请、空间切换、成员管理。
- 知识库：库 CRUD、文档上传与解析进度、分块读写、FAQ、Wiki、图片画廊。
- 会话：会话 CRUD、消息、快速问答（knowledge-chat）、智能体问答（agent-chat）、停止、分叉、回滚、插话。
- 智能体：智能体 CRUD、工具与技能配置、MCP 服务管理。
- 系统：模型管理、数据源、任务队列、审计日志。

## 流式协议

问答接口按 SSE 事件流返回：步骤事件（工具调用开始/结束）、思考事件、答案增量事件与最终完成事件。客户端按事件类型渲染过程与答案。

## 契约文档

完整的 OpenAPI 契约见仓库 docs/swagger.yaml；接口层有契约测试保证文档与实现一致。

# 认证与授权

## 登录认证

POST /api/v1/auth/login 提交邮箱与密码，返回 JWT 访问令牌与刷新令牌；后续请求以 Bearer 方式携带。令牌过期后用刷新令牌换新。

## 多空间身份

登录响应包含用户所属空间列表与当前激活空间；切换空间调用空间切换接口，令牌内的空间身份随之更新。请求的授权校验基于"当前激活空间 + 角色门"。

## 角色门

路由层挂载角色守卫：viewer 及以上可读，contributor 及以上可写内容，admin 及以上可管理成员与配置，owner 才能删除空间。知识库、分块、Wiki 另有细粒度访问门。

## API Key

支持签发带能力范围（检索、问答、管理）与空间范围的 API Key，供脚本与集成调用，权限永不超出签发者的自身权限。

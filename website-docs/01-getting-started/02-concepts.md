# 核心概念

## 知识库与文档

知识库是资料的容器，分文档、FAQ、Wiki 三类。文档支持 PDF、Word、PPT、Excel、CSV、Markdown、HTML、图片等格式，可单传、按 URL 抓取、手动粘贴或整目录上传。文档入库后经过解析、分块、摘要、向量化，最终进入全文与向量双索引。

分块是知识的最小单元，每块都可手动编辑、有版本历史、可回滚，还可以让模型为每块预生成"候选问题"。

## 会话的两种模式

- 快速问答：直接走检索管线，检索到参考资料的片段后生成答案，一步到位，适合确定性的制度类问题。
- 智能推理：由智能体接管，模型自己规划步骤、连环调用工具（查数据库、联网搜索、跑代码等），适合需要动手的复杂任务。

## 智能体与工具

智能体是带系统提示词、模型选择与工具集的可配置运行体。平台内置一个"学业助手"负责默认问答，用户也可以自建智能体。工具分内置（知识检索、数据库查询、数据分析、网页抓取、沙箱命令等）与外部（通过 MCP 协议接入）两类。

## 空间（班级）

空间是多租户隔离单位。在教务场景中一个空间对应一个班级或一个部门：学生是查看者，教师是贡献者，教务处是所有者。知识库与智能体都归属于空间，校级公共资料通过组织共享下发。

## 角色与权限

空间内四级角色：owner（所有者）、admin（管理员）、contributor（贡献者）、viewer（查看者）。系统管理员另有平台级后台，负责用户、模型目录与运行时监控。

## 长期记忆

跨会话的个人记忆条目，需用户确认后才会写入，可随时查看与删除；亦有空间级共享记忆。

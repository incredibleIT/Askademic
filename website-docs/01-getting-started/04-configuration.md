# 配置总览

Askademic 的配置分三层：平台全局默认、知识库级覆盖、智能体级覆盖。下层未显式配置时继承上层。

## 模型

平台按角色使用五类模型，均在系统设置中配置，凭据加密存储：

- KnowledgeQA：答案生成与文档摘要。
- Embedding：入库与检索两端的向量化。
- Rerank：检索结果精排。
- VLLM：本地大模型推理引擎（可选）。
- ASR：语音提问转写（可选）。

每个知识库与智能体可以单独指定模型，不指定则继承系统默认。

## 知识库级设置

每个知识库可覆盖：解析引擎与参数、分块策略、多模态图片管线开关、向量库选型、知识图谱开关。详见[知识库管理](../03-features/01-knowledge-base.md)。

## 系统设置

系统管理员在平台后台管理：存储后端、向量库连通性、任务队列与配额、模型目录发布、用户账号。

## 数据源

外部资料源（飞书、钉钉）可配置定时同步进指定知识库，详见[数据源同步](../03-features/06-datasource.md)。

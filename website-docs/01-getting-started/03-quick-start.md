# 快速上手

## 登录

打开系统首页，使用学校分配的账号登录。演示环境提供四类角色账号（学生、教师、教务、超管），均为 @askademic.local 域邮箱，密码由管理员统一发放，文档中不落明文。

## 创建知识库

1. 进入"知识库"页，点击新建。
2. 选择类型：文档库（默认）、FAQ 库或 Wiki 库。
3. 按需在库设置里覆盖全局默认：解析引擎、分块策略、多模态图片管线、向量库。

## 上传资料

在知识库详情页上传文件，支持拖拽与整目录上传（保留文件夹结构）。解析是异步的，进度时间线里能看到各阶段状态；解析完成后即可提问。

## 提问

新建会话时选择模式：

- 快速问答：适合"学校补办学生证的流程是什么"这类制度问题，回答附带引用出处，点开可溯源到具体片段。
- 智能推理：适合"帮我把这周涉及某门课的所有安排整理成表"这类需要查询数据、动手处理的任务。

## 加入班级空间

教师或教务处生成邀请链接后，学生通过链接注册并自动加入对应班级空间，无需管理员逐个建号。

# 产品介绍

Askademic 是一款面向高校教务场景的智能问答系统，让制度查询、课表成绩等个人事务、常见问题解答都能"问一句就答，回答有据可查"。

Askademic 基于腾讯开源项目 WeKnora（MIT 协议）二次开发而来，在其知识库与智能体底座上，针对校园教务场景做了功能剪裁、身份重塑与学业数据扩展。本项目为毕业设计作品，论文中已声明开源来源。

## 核心能力

- 知识库问答：制度文件、通知公告等资料上传后自动解析入库，提问时混合检索并给出带引用出处的答案。
- 学业数据问答：学生的课表、成绩、考试安排等结构化数据存在学业数据库中，智能体通过数据库工具直接查询作答。
- 多角色空间：学生、教师、教务处各用各的空间，权限隔离，校级知识库可共享给全校只读。
- 网站嵌入：问答入口可以 iframe 或脚本气泡的形式嵌入学校门户页面。

## 与上游 WeKnora 的关系

Askademic 保留了 WeKnora 的核心引擎（文档解析、分块向量化、混合检索、Agent 编排），并做了三类改造：

1. 剪裁：移除教务场景用不到的集成与生态组件，详见[剪裁说明](../06-development/03-trim-notes.md)。
2. 重塑：品牌视觉、产品文案、演示账号与提示词身份全部替换为 Askademic。
3. 扩展：新增学业数据库与相应智能体工具，支撑课表成绩等个人事务问答。

# 版本记录

Askademic 的版本演进以改造里程碑为主轴，详细剪裁与实现记录见仓库 docs/ 目录下的台账与状态文档。

## 里程碑概览

- 品牌重塑：产品名、字标、favicon、界面文案、演示账号全部切换为 Askademic。
- 前端改造：首页、登录、知识库、会话等页面按教务场景重构视觉与文案。
- 仓库剪裁：移除生态组件（CLI/SDK/小程序等）与未使用的数据源连接器。
- 提示词身份：智能体身份声明替换为 Askademic。
- 学业扩展（进行中）：学业数据库、班级空间映射与学业助手智能体。

# Agent 引擎

智能推理模式由 Agent 引擎驱动，核心是一个"推理-行动"循环。

## 执行循环

每轮循环中，模型收到问题、系统提示词与可用工具清单，然后决定：

- 直接产出最终答案，结束循环；或
- 调用一个工具，引擎执行工具并把结果喂回模型，进入下一轮。

界面上"正在检索知识库""正在执行命令"等步骤即循环的实时事件流。

## 工具体系

- 知识类：混合检索、读文档、列文档、图谱查询、搜历史会话。
- 数据类：数据库查询（SQL）、表格分析（DuckDB）、搜长期记忆。
- 网络类：网页搜索（提供商可配）、网页抓取。
- 执行类：沙箱命令执行、沙箱与技能文件读写。
- 交互类：向用户追问。

外部能力通过 MCP 服务接入，支持逐工具开关与调用审批。

## 审批与沙箱

工具按风险分三档：只读放行、修改前确认、自动执行；会话内可临时授权。危险操作在隔离沙箱（容器）中执行，支持交互终端；沙箱内产出的文件统一进入产物库，可预览与下载。

## 上下文管理

引擎负责会话历史的压缩与截断、工具失败的降级重试、思考过程与最终答案的分离展示，保证长会话下的稳定运行。

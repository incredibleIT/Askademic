# RAG 管线

从一份资料到"可以带出处回答问题"，经历入库与检索两段流水线。

## 入库流水线

1. 上传：文件、URL 抓取或手动粘贴；目录上传保留结构。
2. 解析：DocReader 抽取文本与结构；图片走多模态管线（视觉模型生成描述，原图入对象存储，可在图片画廊中浏览）。
3. 分块：按库级策略切分，块可手动编辑、有版本历史。
4. 摘要：为整篇文档生成结构化摘要，供检索层与展示层使用。
5. 向量化：Embedding 模型将每块转为向量。
6. 入索引：全文索引与向量索引同时建立。
7. 候选问题：可让模型为每块预生成能回答的问题，提升召回。

解析为异步任务，进度时间线逐阶段可见，失败可重试或取消。

## 检索流水线

1. 混合召回：全文（关键词命中）与向量（语义相近）两路并行。
2. 融合去重：两路结果合并排序。
3. 精排：Rerank 模型将真正相关的片段上浮。
4. FAQ 与图谱：FAQ 库按相似问匹配直接命中标准答案；开启图谱的库并行一路 Neo4j 关系查询。
5. 生成：参考资料拼装进提示词，模型生成答案，逐句标注引用。

## 引用协议

答案中的引用使用请求局部的资源句柄（chunk://N 指向知识片段），生成后由系统替换为真实链接，保证答案里的每个出处都可点击溯源。

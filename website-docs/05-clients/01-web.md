# Web 界面

Web 界面是 Askademic 的主要使用入口，由后端静态托管，与 API 同源同端口。

## 主要页面

- 首页：问候与快速提问框、知识库/文档/会话统计、最近会话与库动态。
- 知识库：库列表与详情、文档管理、分块治理、库设置、图片画廊。
- 会话：两种模式问答、步骤与引用展示、语音输入、临时附件、分叉与回滚。
- 智能体：智能体列表与编辑器。
- 工具箱：MCP 服务与技能管理。
- 产物库：沙箱产出文件的统一浏览与下载。
- 设置：个人偏好、长期记忆、模型凭据、成员与审计。

## 主题

支持亮暗两套主题与多语言界面；品牌视觉（字标、图标、配色）为 Askademic 定制。

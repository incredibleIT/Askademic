# 剪裁说明

Askademic 是对 WeKnora 的剪裁式二开：先逐线清理不需要的功能，再按教务场景扩展。本页说明剪裁的原则与边界。

## 剪裁原则

1. 剔除优先：删得干净就删；耦合太深则隐藏——前端入口摘除、后端代码保留、文档不再提及。
2. 验证先行：每一步剪裁必须通过构建与测试（go build/test、vite build、页面冒烟）才可提交。
3. 增量记录：剪裁决策与动作在仓库维护者的过程台账中增量记录（该台账属于内部工作文档，不随本仓库分发）。

## 已剪裁（概要）

- 仓库杂物：CLI、Go SDK、微信小程序、Python MCP Server、示例目录。
- 数据源：保留飞书家族与钉钉，移除其余八种连接器。
- 产品文档工具：隐藏（不再授予任何智能体），语料替换为本文档。
- 提示词身份：全部模板的身份行替换为 Askademic。

## 保留的加分项

知识图谱检索（GraphRAG）、自动 Wiki、内置 MCP Server、网站嵌入 Widget、检索评测工具、浏览器扩展——这些能力在毕业设计中作为亮点保留。

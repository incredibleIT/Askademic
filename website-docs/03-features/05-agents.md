# 智能体

## 内置智能体

平台内置"学业助手"作为默认问答智能体：不带预设知识库（跟随会话绑定），持有全套只读工具与空间管理操作，负责快速问答与日常任务。

## 自定义智能体

可创建自己的智能体，配置项包括：系统提示词、模型与精排模型、工具白名单、知识库选择模式、最大迭代轮数、推理力度、头像与开场白。支持复制、导出与按空间共享。

## 工具集

工具按能力声明，智能体按白名单启用：

- 知识类：混合检索、读文档、列文档、图谱查询、搜会话。
- 数据类：数据库查询、表格分析、搜记忆。
- 网络类：网页搜索、网页抓取。
- 执行类：沙箱命令、文件读写。
- 交互类：向用户追问。

## MCP 外部工具

在工具箱页接入外部 MCP 服务（支持 OAuth），接入后可按工具粒度启停；调用遵循与内置工具相同的审批策略。

## 技能

技能是"提示词 + 脚本 + 资源"的组合包，从技能目录安装后赋权给智能体；技能在沙箱内运行。

# 混合检索与引用

## 检索通道

一次提问并行走四条通道：

1. 全文通道：关键词与短语精确命中。
2. 向量通道：语义相近片段召回。
3. FAQ 通道：FAQ 库按相似问匹配，命中即出标准答案。
4. 图谱通道：开启知识图谱的库并行做实体关系查询。

全文与向量结果经融合去重后，由 Rerank 模型精排，最终截取最相关的若干片段进入生成。

## 全局搜索

界面的全局搜索面板（快捷键 Cmd+K）跨库检索知识片段与文档，快速定位资料原文。

## 检索评测

内置评测工具可对一组问答样本统计召回命中率与生成质量（BLEU、ROUGE），用于检索参数调优与实验对比。

## 引用与溯源

答案中的每个事实性论断都可附带引用标记，指向具体知识片段；点开引用可查看原文上下文。引用格式由系统协议控制，保证句内跟随、可点击。

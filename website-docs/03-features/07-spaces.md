# 空间与权限

## 空间

空间是数据与权限的隔离单位。在教务场景中，一个班级建一个空间：班级知识库、班级智能体、班级会话彼此不可见。用户可在多个空间间切换，登录后默认进入其主空间。

## 四级角色

- owner（所有者）：空间全部管理权，含删除空间、管理成员。
- admin（管理员）：成员邀请、知识库与智能体管理。
- contributor（贡献者）：上传文档、编辑分块、创建内容。
- viewer（查看者）：只读使用，提问与浏览。

角色在成员管理页逐人指派；邀请支持邮箱邀请与分享链接注册两种方式，学生通过链接注册后自动落入对应空间与默认角色。

## 组织与校级共享

组织是跨空间的上级单位（对应学校或院系）。知识库与智能体可共享给组织，组织内成员按只读或可编辑权限访问——校级制度库通过该机制全校可见。

## 审计日志

空间级审计日志记录成员与内容的关键操作，供管理员追溯；日志有保留期限。

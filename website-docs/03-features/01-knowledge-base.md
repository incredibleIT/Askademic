# 知识库管理

## 库的类型

- 文档库：常规资料库，文件、URL、手动粘贴三种入口。
- FAQ 库：问答对库，标准问 + 相似问 + 标准答案，Excel 批量导入导出。
- Wiki 库：由文档自动抽取实体生成带引用的页面集合。

## 文档操作

上传（单文件、拖拽、整目录保留结构）、URL 抓取、手动创建；批量重解析、移动、打标签、下载、删除；解析进度时间线逐阶段展示，支持取消与重试。

## 分块治理

每个分块可手动编辑内容，带完整版本历史与一键回滚；可让模型为分块生成候选问题并人工增删；相邻分块可合并预览。

## 库级设置

解析引擎与参数、分块策略、多模态图片管线、向量库选型、知识图谱开关、存储位置，均可按库覆盖平台默认。

## 图片画廊

库内所有图片资产集中浏览，视觉模型生成的图片描述可人工修正，修正后重新参与检索。

## 库的复制与共享

整库复制、克隆出独立副本；通过组织共享把库发布给全校只读（例如校级制度库）。

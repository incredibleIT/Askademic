# 数据源同步

外部资料源可定时同步进知识库，保持内容自动更新。

## 支持的数据源

- 飞书：知识库（Wiki 空间）与云盘文件夹，含国际版 Lark；OAuth2 授权，支持增量同步与删除同步。
- 钉钉：钉钉在线文档知识库；OAuth2 授权，支持增量与删除同步。

## 同步机制

每个数据源配置一个 cron 同步计划，可选增量（推荐）或全量模式；同步拉取的条目走与手动上传相同的解析入库管线。源端删除的文档可配置为同步删除知识库中的对应文档。

## 资源选择

授权后可浏览源端目录树，按目录或文档勾选同步范围；飞书云盘模式直接粘贴文件夹链接即可。

## 同步日志

每次同步记录启动时间、条目统计（新建/更新/删除/跳过/失败）与逐条错误样本；日志保留天数按数据源配置。失败条目在下轮增量中自动重试。
